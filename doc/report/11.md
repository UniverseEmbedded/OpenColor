## 结论：问题在 `stl_poly_compare.load_stl_and_project_to_2d` 的“孔洞处理”

你仓库里这段代码在这里：

`py_module/prototypes/src/oc_prototypes_02/gen_model_exporter_01/stl_poly_compare.py`

当前逻辑是：

1. `mesh.section(...)` 得到截面曲线
2. `slice_result.to_planar()` 得到 `Path2D`
3. 遍历 `slice_2d.entities`（或等价的闭合环），把每个闭合环直接 `Polygon(coords)`
4. 对这些 Polygon 做 `unary_union(polys)`

**问题点**：截面会返回“外轮廓 + 若干内轮廓（孔洞边界）”的多条闭合环。你现在把它们都当“实心面” union 起来，相当于把孔洞“填实”，面积当然变大。

## 同时解释你看到的 “slice_area=140.7%”

你 debug 包里写的 slice_area 算法是：

```python
slice_area = abs(m.volume) / layer_height_mm
```

对复杂、多洞、且可能存在局部 winding/数值误差的网格，`trimesh.volume` **并不总能可靠反映“外减内”的净体积**（尤其当组件很多、孔洞很多时更敏感），所以它可能会向“把洞当实体”那边偏，恰好给出 **1991.24 mm²** 这种“更像把环面积累加/填洞”的结果。

你现在既然已经在对比阶段有 `section→2D` 能得到**正确净面积（1415.70）**，建议把 slice_area 的“真值”改成 **截面 even-odd 重建后 2D polygon 的 area**，别再用 `volume/height` 做面积守恒的指标（它在这个场景下会误导）。

## 你该怎么改（最小补丁）

只改 `stl_poly_compare.py` 的 `load_stl_and_project_to_2d`：
不要把每条环都 union；要像你 SVG 解析那样做 **嵌套树 + 奇偶深度** 来恢复 holes。

下面给你一段可以直接放进去替换的实现（完全不依赖 `polygons_full`，避开 shapely2/trimesh 的兼容坑）：

```python
# stl_poly_compare.py
import numpy as np
from shapely.geometry import Polygon
from shapely.ops import unary_union

def _loops_to_evenodd_polygon(loops_2d) -> Polygon:
    """
    loops_2d: list[np.ndarray], each (N,2) closed loop vertices (planar coords)
    Return shapely geometry with holes resolved using even-odd nesting.
    """
    rings = []
    for pts in loops_2d:
        if pts is None or len(pts) < 3:
            continue
        p = Polygon(pts)
        if not p.is_valid:
            p = p.buffer(0)
        if p.is_empty:
            continue
        if p.geom_type == "Polygon":
            rings.append(p)
        else:
            rings.extend([g for g in p.geoms if g.geom_type == "Polygon" and g.area > 1e-9])

    if not rings:
        return Polygon()

    boxes = [r.bounds for r in rings]
    areas = [abs(r.area) for r in rings]
    reps  = [r.representative_point() for r in rings]
    order = np.argsort(areas)[::-1]

    parent = [None] * len(rings)
    depth  = [0] * len(rings)

    # find smallest containing ring as parent
    for i in order:
        x0,y0,x1,y1 = boxes[i]
        best = None
        best_area = None
        for j in order:
            if j == i or areas[j] <= areas[i]:
                continue
            bx0,by0,bx1,by1 = boxes[j]
            if bx0 <= x0 and by0 <= y0 and bx1 >= x1 and by1 >= y1:
                if rings[j].contains(reps[i]):
                    if best_area is None or areas[j] < best_area:
                        best = j
                        best_area = areas[j]
        parent[i] = best

    for i in range(len(rings)):
        d = 0
        p = parent[i]
        while p is not None:
            d += 1
            p = parent[p]
        depth[i] = d

    # shells are even depth
    shells = [i for i,d in enumerate(depth) if d % 2 == 0]
    holes_map = {s: [] for s in shells}

    # holes are odd depth whose parent is shell
    for i in range(len(rings)):
        p = parent[i]
        if p is not None and (depth[i] % 2 == 1) and (depth[p] % 2 == 0):
            holes_map[p].append(i)

    polys = []
    for s in shells:
        shell = rings[s]
        holes = [list(rings[h].exterior.coords) for h in holes_map[s]]
        poly = Polygon(shell.exterior.coords, holes)
        if not poly.is_valid:
            poly = poly.buffer(0)
        if poly.is_empty:
            continue
        if poly.geom_type == "Polygon":
            polys.append(poly)
        else:
            polys.extend([g for g in poly.geoms if g.area > 1e-9])

    if not polys:
        return Polygon()
    return unary_union(polys)


def load_stl_and_project_to_2d(stl_path: Path, layer_z_mm: float) -> Polygon:
    mesh = trimesh.load_mesh(stl_path)

    slice_result = mesh.section(plane_origin=[0, 0, layer_z_mm], plane_normal=[0, 0, 1])
    if slice_result is None:
        return Polygon()

    slice_2d, transform_matrix = slice_result.to_planar()
    if slice_2d is None:
        return Polygon()

    # Use discrete loops, then map back to world XY
    loops_world = []
    for loop_local in slice_2d.discrete:
        if loop_local is None or len(loop_local) < 3:
            continue
        ones = np.ones((loop_local.shape[0], 1))
        coords_h = np.hstack([loop_local, np.zeros((loop_local.shape[0], 1)), ones])
        coords_3d_h = (transform_matrix @ coords_h.T).T
        xy = coords_3d_h[:, :2] / coords_3d_h[:, 3:4]
        loops_world.append(xy)

    return _loops_to_evenodd_polygon(loops_world)
```
