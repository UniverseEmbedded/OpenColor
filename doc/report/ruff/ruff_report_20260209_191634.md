### 规则说明

- **E/W** 规则：pycodestyle（代码风格）
- **F** 规则：Pyflakes（逻辑错误和未使用代码）
- **B** 规则：flake8-bugbear（潜在 Bug，如循环变量捕获问题）
- **A** 规则：flake8-builtins（检查是否覆盖 Python 内置函数）
- **PLC/PLE/PLW** 规则：Pylint（代码质量、错误、警告）
- **RUF** 规则：Ruff 特定规则（额外代码质量检查）
