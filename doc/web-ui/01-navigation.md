# 导航结构

## 一级导航

| 标签页 | 说明 |
|--------|------|
| 校准 | 校准流程：校准板生成、照片校正与样本提取、模型训练 |
| 生成 | 生成流程：叠色像素生成、矢量化、模型导出 |
| 素材库 | 管理校准板、照片、训练好的模型、生成的文件和材料配置 |
| 设置 | 应用设置 |

## 二级导航

### 校准标签页

| 子项 | 说明 |
|------|------|
| 校准板生成 | 生成8色校准板的规格文件和3MF打印文件 |
| 照片校正与样本提取 | 手动4点透视校正色盘照片，提取颜色样本，支持禁用缺陷格子 |
| 模型训练 | 使用RT光学模型+GPR训练颜色预测模型 |

### 生成标签页

| 子项 | 说明 |
|------|------|
| 叠色像素生成 | 基于训练好的模型计算每个像素的颜色配方 |
| 矢量化 | 将像素掩码转换为SVG矢量多边形 |
| 模型导出 | 从SVG重建3D网格，导出STL和3MF格式 |

### 素材库标签页

| 子项 | 说明 |
|------|------|
| 校准板 | 管理的校准板规格文件和3MF文件 |
| 照片 | 管理的色盘照片和校正结果 |
| 模型 | 训练好的RT+GPR颜色预测模型 |
| 材料 | 耗材配置和耗材组管理 |
| 生成文件 | 叠色像素图、SVG、STL、3MF等生成结果 |

### 设置标签页

| 子项 | 说明 |
|------|------|
| 通用 | 语言、主题等基础设置 |
| 项目 | 默认项目路径、自动保存等 |
| 引擎 | Python引擎配置、GPU加速选项 |

## 流程图入口

流程图不占用一级导航，放置在以下位置：
- 帮助菜单中的"流程图"选项
- 首次打开应用时弹出
- 校准和生成标签页顶部显示当前流程进度

## 设计决策说明

### 照片校正与样本提取合并

将原"照片校正"和"样本构建"两个环节合并，原因：
- 两个环节都围绕"照片"这个核心对象
- 用户流程更连贯：上传照片 → 校正 → 提取样本 → 标记坏格子
- 支持禁用缺陷格子功能，让用户可以"凑合"使用有缺陷的打印色盘

### 叠色像素生成

原名"掩码生成"改为"叠色像素生成"，原因：
- "掩码"过于技术化，用户不易理解
- "叠色像素"直观表达功能：计算每个像素需要叠加哪些颜色

### AprilTag不予实现

3D打印的AprilTag与喷墨/激光打印到纸上的识别率不同，在3D打印场景下识别效果不佳，因此UI中仅提供手动4点选择功能。

### 颜色模型

新管线使用RT光学模型+GPR残差修正，不再使用LUT查找表。模型训练输出color_model.json，叠色像素生成环节使用该模型进行实时颜色预测。
