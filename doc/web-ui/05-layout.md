# 布局设计

## 大窗口模式（宽度 >= 1024px）

### 整体布局

左侧固定边栏，右侧主内容区自适应。

### 左侧边栏

**宽度：** 240px，固定不变

**结构（从上到下）：**

1. **Logo区域**（高度 64px）
   - 应用图标 + 应用名称

2. **导航区域**（自适应高度）
   - 一级导航竖排：校准、生成、素材库、设置
   - 点击一级导航展开二级导航（手风琴效果）
   - 二级导航缩进显示（左侧缩进 16px）
   - 当前选中项高亮显示

3. **工作区选择器**（固定在底部）
   - 显示当前工作区名称
   - 点击展开下拉菜单

### 右侧主内容区

**结构（从上到下）：**

1. **页面标题栏**（高度 56px）
   - 显示当前完整路径：一级 > 二级
   - 右侧显示操作按钮

2. **工作区**（剩余高度）
   - 左右分栏布局（配置面板 + 预览区域）

---

## 小窗口模式（宽度 < 1024px）

### 整体布局

顶部固定标题栏，下方主内容区全宽。

### 顶部标题栏

**高度：** 56px，固定不变

**结构（从左到右）：**

1. **Logo区域**
   - 应用图标或简化名称

2. **一级导航**（横向排列）
   - 校准、生成、素材库、设置
   - 点击选中，当前项高亮

3. **工作区选择器**（右侧）
   - 简化显示（仅图标或缩写）
   - 点击展开下拉菜单

### 二级导航栏

**位置：** 标题栏下方

**高度：** 48px

**布局：**
- 横向排列当前一级导航下的二级导航项
- 点击选中，当前项高亮
- 左右可滑动（当项目较多时）

### 主内容区

**结构：**
- 全宽显示
- 直接显示页面工作区
- 上下堆叠布局（配置面板在上，预览区域在下）

---

## 导航交互说明

### 大窗口模式

- 点击一级导航：展开/收起对应的二级导航
- 点击二级导航：切换到对应页面
- 同时只能展开一个一级导航（手风琴模式）

### 小窗口模式

- 点击一级导航：
  - 切换到该一级导航
  - 在下方显示对应的二级导航栏
  - 默认选中第一个二级导航项
- 点击二级导航：切换到对应页面

---

## 工作区选择器

### 大窗口

- 显示在边栏底部
- 显示完整工作区名称
- 点击展开：最近工作区列表 + 新建/打开按钮

### 小窗口

- 显示在标题栏右侧
- 简化显示（图标或前几个字符）
- 点击展开相同菜单

---

## 响应式断点

- **大窗口：** 宽度 >= 1024px
- **小窗口：** 宽度 < 1024px

切换窗口大小时自动调整布局，无需刷新页面。
