# 预计数据尺寸

本文档列出OpenColor各环节产生的数据文件及其预计大小，用于指导数据传输和存储设计。

## 大文件（>1MB）

| 文件类型 | 预计大小 | 产生环节 | 用途 | 传输建议 |
|----------|----------|----------|------|----------|
| STL文件 | 30-100MB | 模型导出 | 3D打印、Web预览 | 传文件路径，Web通过URL加载 |
| 3MF文件 | 20-50MB | 模型导出 | 3D打印、Web预览 | 传文件路径，Web通过URL加载 |
| 输入图像 | 5-20MB | 用户上传 | 叠色像素生成 | 传文件路径，预览用缩略图 |
| 掩码PNG | 10-30MB | 叠色像素生成 | 预览、矢量化输入 | 传文件路径，预览用缩略图 |
| 校正后照片 | 5-15MB | 照片校正 | 样本提取 | 传文件路径，预览用缩略图 |
| SVG文件 | 1-10MB | 矢量化 | 预览、模型导出 | 传文本内容或路径 |
| 样本数据集 | 5-20MB | 样本提取 | 模型训练 | 传文件路径 |

## 中等文件（100KB-1MB）

| 文件类型 | 预计大小 | 产生环节 | 用途 | 传输建议 |
|----------|----------|----------|------|----------|
| 网格叠加图 | 500KB-2MB | 照片校正 | 预览校正效果 | Base64或路径 |
| 校准前预览 | 200KB-1MB | 样本提取 | 对比显示 | Base64或路径 |
| 校准后预览 | 200KB-1MB | 样本提取 | 对比显示 | Base64或路径 |
| 误差热图 | 500KB-2MB | 叠色像素生成 | 预览配色误差 | Base64或路径 |

## 小文件（<100KB）

| 文件类型 | 预计大小 | 产生环节 | 用途 | 传输建议 |
|----------|----------|----------|------|----------|
| 颜色模型 | 10-100KB | 模型训练 | 叠色像素生成 | JSON直接传递 |
| 规格文件 | 1-10KB | 校准板生成 | 照片校正引用 | JSON直接传递 |
| 校正参数 | <1KB | 照片校正 | 记录四角坐标 | JSON直接传递 |
| 清单文件 | 1-5KB | 各环节 | 记录输出文件列表 | JSON直接传递 |
| 质量报告 | 1-10KB | 矢量化 | 重叠检测结果 | JSON直接传递 |
| 工作区索引 | <1KB | 工作区创建 | 记录工作区元数据 | JSON直接传递 |
| 项目设置 | <1KB | 用户设置 | 记录默认配置 | JSON直接传递 |
| APP设置 | <1KB | 用户设置 | 记录应用配置 | JSON直接传递 |

## 缩略图尺寸

用于Web预览的缩略图：

| 原文件类型 | 缩略图尺寸 | 预计大小 |
|------------|------------|----------|
| 照片（校正前后） | 800x600 | 50-100KB |
| 掩码PNG | 512x512 | 30-80KB |
| 误差热图 | 512x512 | 30-80KB |
| STL/3MF预览 | 400x300渲染图 | 20-50KB |

## 存储建议

### 工作区目录总大小估算

一个典型工作区（打印一张120x120mm图像）：

```
输入图像：10MB
校正后照片：8MB
样本数据集：10MB
颜色模型：50KB
掩码PNG（5层）：50MB
SVG文件（5层）：5MB
STL文件（5层）：200MB
3MF文件：30MB
---------------------------------
总计：约313MB
```

### 存储优化建议

1. **自动清理**：可选删除中间文件（掩码、SVG），保留最终结果
2. **压缩归档**：完成的项目可压缩为zip，减少占用
3. **云同步提示**：大文件（STL/3MF）不建议同步到云盘

## 传输优化建议

### Web ↔ Rust

| 数据类型 | 方式 | 说明 |
|----------|------|------|
| 小文件（<100KB） | JSON直接传递 | 设置、配置、清单 |
| 中等文件（100KB-1MB） | Base64编码 | 预览图、缩略图 |
| 大文件（>1MB） | 文件路径 | Web通过Tauri API读取本地文件 |

### Rust ↔ Python

| 数据类型 | 方式 | 说明 |
|----------|------|------|
| 配置参数 | PyO3直接传递 | 字典、列表 |
| 文件路径 | 字符串传递 | Python读取本地文件 |
| 大数组 | 文件或共享内存 | 图像数据、掩码数据 |

### Python ↔ C++

| 数据类型 | 方式 | 说明 |
|----------|------|------|
| 配置参数 | pybind11直接传递 | 基本类型 |
| 图像/掩码数组 | numpy buffer | 零拷贝共享内存 |
| 求解结果 | 返回numpy数组 | 批量数据 |
