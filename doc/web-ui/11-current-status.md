## 交互方式说明

### 1. 导航交互

```
┌─────────────────────────────────────────┐
│  [Logo]  Calibrate  Generate  Library  [Settings]  │  ← 一级导航
├─────────────────────────────────────────┤
│  [Board Gen] [Photo Warp] [Model Train]            │  ← 二级导航（Calibrate下）
├─────────────────────────────────────────┤
│  Calibrate / Board Gen / [Current Page]            │  ← 面包屑
└─────────────────────────────────────────┘
```

- **一级导航**：点击切换主功能模块
- **二级导航**：点击切换子页面，小窗口下可横向滚动
- **面包屑**：显示当前位置，点击可返回上级

### 2. 校准板生成交互

```
┌─────────────────────────────────────────┐
│  生成配置                              │
│  规格名称 [8-Color Board    ]          │
│  板子数量 [8               ]           │
│  格子缩进 [0.0             ] mm        │
│  层高     [0.2             ] mm        │
│  [ ] 包含 AprilTag                     │
│  [ ] 包含侧边白色三角形                │
│  [▶ 生成校准板]                        │
└─────────────────────────────────────────┘
```

### 3. 照片校正交互

```
┌─────────────────────────────────────────┐
│  文件选择                              │
│  校准板规格 [▼ 选择规格文件]           │
│  照片       [选择照片]                 │
│                                        │
│  角点控制                              │
│  [↺ 逆时针] 0° [顺时针 ↻]             │
│  [清空角点]                            │
│  [执行校正]                            │
└─────────────────────────────────────────┘
```

- **角点选择**：在画布上点击添加角点（最多4个）
- **角点拖拽**：拖拽调整角点位置
- **旋转**：点击旋转按钮调整照片方向

### 4. 模型训练交互

```
┌─────────────────────────────────────────┐
│  训练配置                              │
│  数据集   [选择数据集]                 │
│  耗材组   [default         ]           │
│  层高     [0.2             ] mm        │
│  光学模型 [RTS ▼]                      │
│  [✓] 使用 Vulkan GPU加速               │
│  GPR核函数 [RBF ▼]                     │
│  [▶ 开始训练]                          │
└─────────────────────────────────────────┘
```

### 5. 工作区交互

```
┌─────────────────────────────────────────┐
│  [📁 workspace_name]  [▼]              │  ← 工作区选择器（Header）
│  C:\path\to\workspace                   │
└─────────────────────────────────────────┘
```

- **切换工作区**：点击选择器 → 下拉菜单 → 选择工作区
- **创建新工作区**：设置→工作区→"Create New Workspace"按钮
- **打开其他工作区**：设置→工作区→"Open Other Workspace"按钮
- **在资源管理器中打开**：设置→工作区→当前工作区卡片→文件夹图标

### 6. 小窗口处理

当窗口尺寸 ≤640px 宽度或 ≤480px 高度时：
- 显示覆盖层提示"窗口尺寸过小"
- 提供"不再显示"按钮
- 设置保存在本地存储
