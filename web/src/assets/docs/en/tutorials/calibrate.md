# Calibration Guide

Fit material transparency and haze parameters by printing and photographing a calibration board.

### Capture Suggestions
Keep light and exposure fixed, avoid glare and shadows. Use a consistent lighting environment for all calibration photos.

### Common Failures
If auto-detection fails, manually select corners and ensure the image is clear. Ensure there is significant contrast between the board and the background.

## FAQ

*   **Blurry photos**: Lead to unstable fitting. Please ensure the camera is in focus.
*   **Batch differences**: Suggest using the same batch of filament for calibration.
*   **Parameter consistency**: Print height and layer thickness must match the generation parameters; otherwise, the fit results may fail during actual printing.
