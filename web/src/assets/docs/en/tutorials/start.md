# Get Started

## Steps
1. Import SVG or PNG in the Generate page
2. Select the matching filament profile
3. Set dimensions and layers, then click Generate
4. Import the STL into your slicer and start printing

## Supported Formats
- SVG (Recommended): unlimited scaling and perfect layering
- PNG/JPG: automatic color quantization

## Troubleshooting
- Generation failed? Check the console log
- Color mismatch? Update the profile in Calibrate
