# 拓竹A系列多色打印与料线选通器限位装置指南

## 拓竹A系列如何实现4色以上的多色打印

### 基础架构

拓竹A系列（如A1、A1 mini）打印机本身支持通过AMS（Automatic Material System）实现多色打印。标准配置下：

- **单个AMS**：支持4色打印
- **AMS Hub集线器**：通过连接多个AMS，可扩展至最多16色打印

### 实现5~16色打印的方案

#### 1. 硬件连接方式

拓竹A系列要实现4色以上的多色打印，需要以下组件：

| 颜色数量 | 所需设备 |
|---------|---------|
| 4色 | 1台AMS |
| 8色 | 2台AMS + AMS Hub |
| 12色 | 3台AMS + AMS Hub |
| 16色 | 4台AMS + AMS Hub |

#### 2. AMS Hub（料线选通器/集线器）的作用

AMS Hub是连接多台AMS与打印机的核心组件：

- **信号路由**：将打印机的控制信号分配给各个AMS
- **料线选通**：根据当前打印需求，自动选择对应AMS中的料线
- **缓冲管理**：协调多台AMS之间的送料和退料动作

#### 3. 工作流程

1. **切片准备**：在Bambu Studio中配置多色模型，指定每种颜色对应的AMS槽位
2. **打印启动**：打印机通过AMS Hub向对应AMS发送选通信号
3. **动态切换**：当需要换色时，AMS Hub切换至目标AMS，执行退料/送料操作
4. **协同工作**：各AMS轮流工作，实现无缝多色打印

#### 4. 固件要求

- A1系列需升级至固件版本 **01.07.00.00** 或更高
- 支持AMS/AMS 2 Pro/AMS HT任意组合
- **注意**：不支持与AMS lite混合使用

## 料线选通器限位装置

### 问题描述

在使用AMS Hub（料线选通器）时，用户经常遇到**卡料**问题：

- PTFE料管插入不到位或角度不正
- 料线在进入选通器时发生弯折或偏移
- 频繁卡料导致打印中断，影响打印成功率

### 解决方案：PTFE管限位装置

#### 装置功能

限位装置是一个3D打印配件，用于：

1. **固定PTFE料管**：确保料管以正确角度和深度插入选通器
2. **防止偏移**：限制料管的水平和垂直移动
3. **减少摩擦**：保持料线顺畅通过选通器入口

#### 安装建议

1. **料管处理**：
   - 使用切管刀严格水平切割PTFE料管
   - 确保切口平整无毛刺
   - 安装时用力将料管插到底

2. **装置安装**：
   - 将限位装置固定在选通器入口位置
   - 确保PTFE管穿过限位装置的导向孔
   - 调整位置使料管保持自然直线状态

#### 进阶优化

如果仅安装限位装置后仍有卡料现象，可配合以下改造：

- **打磨选通器内部**：将选通器上半部分内部可拆卸带磁铁的塑料圆筒中间的出口平面，从平面打磨成45度斜角，减少料线通过的阻力

### 参考资源

- MakerWorld模型页面：[PTFE管限位装置](https://makerworld.com.cn/zh/models/1731317)
- 推荐打印配置：0.2mm层高，2层墙，15%填充

### 注意事项

- 安装时可能需要先关闭打印机并拔掉线缆和料管
- 部分限位装置设计需要支撑结构
- 建议配合顶部支架使用以获得最佳效果
