# 从位图做成品：PNG/JPG 工作流（插画/照片）

位图适合内容丰富的插画/照片，但也最容易出现“碎细节 → 边界破碎 → 切片奇怪”的问题。

---

## 1. 位图适合什么？不适合什么？

适合：
- 插画、渐变、照片风格（你能接受一定的“像素化/量化”）

不适合：
- 超细线条、超小文字、极细碎纹理（会变成噪声边界）

---

## 2. 导入前处理（强烈建议）

在导入前做这几件事，成功率会大幅提升：

1) **降噪**：去掉颗粒/压缩噪点  
2) **提高对比度**：让主体与背景更分明  
3) **减少颜色复杂度**：过多颜色会导致区域过碎  
4) **放大最小特征**：细线变粗，小字改大或删掉

---

## 3. 生成时的参数建议（用户向）

- 想要细节：增加层数（但打印时间会显著增加）  
- 想要更稳：减少层数、提高最小特征尺寸、减少颜色数  
- 如果边界“糊/锯齿”：尝试提高输入分辨率或改用 SVG

---

## 4. 常见问题

### A) 切片预览出现很多薄壁/毛刺
- 原因：位图噪点导致区域碎裂  
- 解决：降噪、减少颜色数、增大最小特征

### B) 交界处漏底/白边
- 原因：边界碎裂或区域太小  
- 解决：简化图案；优先把关键轮廓改成 SVG
