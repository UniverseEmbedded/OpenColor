# 导出与切片：STL / 3MF 怎么选

---

## 1) 我该导出 STL 还是 3MF？

### 选择 3MF（推荐场景）
- 你需要在切片器里更方便地处理多对象/多材料
- 你希望保留更多“对象语义”（例如对象分组/材料信息）
- 多色打印工作流优先考虑

### 选择 STL（通用场景）
- 你只想先验证几何是否正确
- 单色试打或工程验证
- 某些工具链只接受 STL

---

## 2) 切片时的关键检查（所有人都要做）

1) **预览边界**：交界处是否有缝/重叠？  
2) **薄壁与毛刺**：是否出现不应该出现的细碎墙线？  
3) **打印方向**：是否需要调整摆放方向以提升表面效果？  
4) **材料分配**：多实体/多对象是否都分配到正确的耗材？

---

## 3) 常见切片异常与对应动作

### 切片预览边界抖动、出现薄壁
- 原因：图案过碎、噪点、或 SVG 路径过复杂  
- 解决：减少细节/颜色，简化路径，增大最小特征

### 某些区域消失/很薄
- 原因：区域过小，小于喷嘴与线宽能力  
- 解决：增大尺寸、加粗线条、减少极小细节
