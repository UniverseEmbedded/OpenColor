# 快速入门：从导入到打印（10 分钟闭环）

目标：把一张图/一个 SVG 变成可打印的分层模型，然后在切片器里分配耗材并打印。

---

## 1. 选择输入类型（很重要）

- **SVG（推荐）**：适合 Logo、图标、线稿、像素风、大色块。边界更清晰。
- **PNG/JPG**：适合插画/照片，但更容易出现碎细节、噪点导致边界破碎。

> 如果你不确定：先试 SVG。位图先做降噪/提高对比度再导入。

---

## 2. 导入与设置

1) 点击 **导入**，选择 SVG/PNG/JPG。  
2) 选择一个 **Profile（耗材/打印配置）**。  
3) 设置 **成品尺寸**、**层数/高度（与实际打印参数保持一致）**。  
4) 点击 **生成**。

---

## 3. 导出与切片

1) 导出 **STL 或 3MF**（见《导出与切片》）。  
2) 打开切片器：  
   - 如果导出的是 **多实体 STL**：按实体分别分配耗材/颜色  
   - 如果导出的是 **3MF**：通常会保留对象/材料语义，分配更直观  
3) 选择你的打印机与耗材，正常切片并打印。

---

## 4. 失败时怎么做（最短路径）

- **生成失败**：打开“日志/诊断”面板，先看是否是输入图太碎（位图）或路径太复杂（SVG）。  
- **颜色不准**：先做校准（见《校准全流程》），并确认校准时的层高/层数与生成/打印一致。  
- **边缘白边/漏底**：优先换 SVG 或对 SVG 做“简化路径/合并形状”，见《常见问题排障》。

---

## 5. 一个小建议：先做小样

第一次用新耗材/新 Profile：建议先打印小尺寸样品（同层高/同层数），确认颜色与边界质量，再打印大件。
