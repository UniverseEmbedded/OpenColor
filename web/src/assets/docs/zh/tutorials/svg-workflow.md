# 从矢量做成品：SVG 工作流（Logo/线稿）

SVG 的边界清晰，是最推荐的输入格式。  
但 SVG 也可能“看起来闭合”，实际包含大量短边、重复点、自交或极小孔洞，导致生成失败或边界异常。

---

## 1. 导入前的 SVG 健康检查（你可以在任意矢量软件做）

建议在导入前做：

- **合并形状/布尔整理**（把层叠的形状合成干净区域）  
- **简化路径**（减少无意义控制点与极短边）  
- **删除极小孔洞/孤立小岛**（小到打印不出来的细节会害你）  
- **确保轮廓闭合**（避免开口路径）

---

## 2. 适合 SVG 的内容

- 大色块 Logo / 图标  
- 线稿（线宽要足够）  
- 像素风（方块边界）  
- 需要干净边界的作品

---

## 3. 常见问题

### A) 生成失败
- 多数是“路径太复杂/自交/短边过多”  
- 解决：简化路径、合并形状、删除极小孔洞，再生成

### B) 边缘出现白边/漏底
- 多数是“边界在某些局部非常碎/非常近”  
- 解决：提高最小特征；简化路径；必要时增大整体尺寸
