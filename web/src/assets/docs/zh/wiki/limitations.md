# 材料与外观的局限：丝绸/强反光/半透明

这页告诉你：哪些情况“不是你操作错了”，而是材料与光学特性让结果更难预测。

---

## 1) 丝绸/强反光材料
特点：随观察角度变化大，表面高光明显。  
影响：
- 同一物体在不同角度看颜色差异大
- 拍照校准更容易被高光污染

建议：
- 关闭 HDR，尽量使用柔光环境
- 优先做小样
- 容忍一定偏差（这种材料天然更不可控）

---

## 2) 透明/半透明材料
特点：透光强，叠层影响更明显。  
影响：
- 层数/层高变化会更明显地改变观感
- 校准参数一致性更重要

建议：
- 层高/层数尽量固定
- 换批次材料后优先重校准

---

## 3) 极细节图案
特点：细节接近打印最小特征。  
影响：
- 边界破碎、白边/漏底
- 切片器产生薄壁/毛刺

建议：
- 增大尺寸/加粗线条
- 减少颜色与细碎纹理
