# Profile 指南：如何选择与维护

---

## 1) 我该选哪个 Profile？

按“材料类型”先选：
- 透明/半透明材料：更依赖校准，颜色变化更敏感
- 哑光材料：通常更稳定
- 丝绸/强反光：观感更受角度影响，误差更不可控（见《局限》）

按“打印参数”再选：
- 你计划用的层高/层数，应与 Profile 推荐范围一致
- 若你改了层高/喷嘴/主要温度，建议复制一个新 Profile 并重新校准

---

## 2) 什么时候必须新建/重校准 Profile？

- 换了材料类型或供应商
- 换了喷嘴直径
- 层高变化明显（例如 0.16 → 0.2）
- 同材料但换了批次，颜色/透光变动明显
- 你发现预览长期系统性偏差

---

## 3) 维护建议

- 给 Profile 命名带上关键参数：材料名 + 层高 + 机器
- 每个 Profile 至少保留一组“验证小样”
- 先用小样验证再做大件，能省大量时间
