# RT薄层堆叠算法（RT Slab Stacking Algorithm）

## 概述

RT薄层堆叠算法是一种用于预测多层半透明材料堆叠后颜色表现的物理模型。该算法广泛应用于3D打印多色混色预测、涂料层叠效果模拟等领域。

与Kubelka-Munk理论不同，本算法采用**非相干薄层叠加**方法，通过计算每一层的有效反射率(R)和透射率(T)，结合多次反射叠加原理来预测最终颜色。

## 核心原理

### 1. 薄层模型

将每一层材料视为一个具有有效光学参数的薄层：

- **反射率 (r)**：光线在层内表面反射的比例
- **透射率 (t)**：光线穿透该层的比例

对于每一层材料，参数化表示为：

```
r = sigmoid(α)                          # 反射率参数
t = sigmoid(β) × (1 - r)                # 透射率参数
```

其中：
- `α` (alpha)：反射率的对数几率参数
- `β` (beta)：透射率的对数几率参数
- `sigmoid` 函数确保：0 ≤ r ≤ 1，0 ≤ t ≤ 1-r

### 2. 层间叠加公式

当多层材料堆叠时，使用以下递推公式计算整体反射率：

```
R_next = r + (t² × R_prev) / (1 - r × R_prev)
```

其中：
- `R_prev`：前一层（或基底）的反射率
- `R_next`：叠加当前层后的总反射率
- `r, t`：当前层的反射率和透射率

这个公式考虑了光线在层间的多次反射效应。

### 3. 基底处理

最底层（基底）的反射率 `Rb` 同样通过sigmoid参数化：

```
Rb = sigmoid(γ)
```

其中 `γ` (gamma) 是基底反射率参数。

## 算法流程

### 阶段一：参数拟合

1. **数据准备**
   - 收集已知配方（材料层序列）及其测量颜色
   - 将RGB测量值转换到CIE Lab色彩空间

2. **初始化参数**
   - 对每个材料初始化 `α ≈ -3.0`（低反射）
   - 初始化 `β ≈ 3.0`（高透射）
   - 初始化基底 `γ ≈ 1.0`（Rb ≈ 0.73）

3. **优化拟合**
   - 使用最小二乘法优化参数
   - 在Lab空间计算预测颜色与实测颜色的差异
   - 采用Huber损失函数提高鲁棒性
   - 添加L2正则化防止过拟合

### 阶段二：颜色预测

1. **层序列解析**
   - 将材料序列转换为索引矩阵
   - 支持两种顺序：自上而下(top-first)或自下而上(bottom-first)

2. **逐层计算**
   - 从基底开始，依次叠加每一层
   - 应用层间叠加公式更新总反射率

3. **颜色转换**
   - 将线性反射率转换为sRGB空间
   - 输出最终预测颜色

## 数学细节

### Sigmoid函数

```python
sigmoid(x) = 1 / (1 + exp(-x))
```

为防止数值溢出，通常将输入限制在 [-20, 20] 范围内。

### 色彩空间转换

1. **sRGB → 线性RGB**
   ```
   如果 sRGB ≤ 0.04045:
       linear = sRGB / 12.92
   否则:
       linear = ((sRGB + 0.055) / 1.055)^2.4
   ```

2. **线性RGB → sRGB**
   ```
   如果 linear ≤ 0.0031308:
       sRGB = linear × 12.92
   否则:
       sRGB = (1.055 × linear^(1/2.4)) - 0.055
   ```

3. **RGB → Lab**
   - 先转换到XYZ色彩空间
   - 再转换到CIE Lab空间
   - 使用Delta E CIE76计算颜色差异

### 损失函数

```
损失 = Σ(ΔE) + λ × ||参数||²
```

其中：
- `ΔE`：预测颜色与实测颜色的CIE76色差
- `λ`：正则化系数（通常 1e-3）
- `||参数||²`：参数向量的L2范数

## 两种参数模式

### 1. 层无关模式 (Layer-Independent)

每个材料只有一组参数 `(α, β)`，不随层位置变化。

- **优点**：参数少，不易过拟合
- **缺点**：无法捕捉层位置对光学特性的影响

### 2. 层相关模式 (Layer-Dependent)

每个材料在每个层位置都有独立参数 `(α_l, β_l)`。

- **优点**：更灵活，可建模层位置效应
- **缺点**：参数多，需要更多训练数据

## 应用场景

### 3D打印多色混色

在3D打印中，通过堆叠不同颜色的薄层来创建新颜色：

1. **校准阶段**：打印色卡，测量实际颜色，拟合材料参数
2. **预测阶段**：输入目标颜色，算法预测所需层序列
3. **打印执行**：按预测序列打印各层

### 涂料/油墨层叠

预测多层涂料或油墨叠加后的最终颜色效果。

## 实现要点

1. **数值稳定性**
   - 分母 `1 - r × R` 需要限制最小值（如 1e-6）防止除零
   - 反射率结果限制在 [0, 1] 范围内

2. **浮点精度**
   - 使用float64进行参数优化以保持有限差分敏感性
   - 最终输出可转换为float32

3. **空层处理**
   - 定义特殊材料"EMPTY"表示无材料
   - EMPTY层的参数固定为：r = 0, t = 1（完全透明）
